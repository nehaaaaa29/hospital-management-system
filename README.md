# 🏥 Hospital Management System

A RESTful Hospital Management System built using Spring Boot, Spring Data JPA, Hibernate, and PostgreSQL. This project manages patients, doctors, departments, appointments, and insurance details through a layered architecture.

## ✨ Features

- 👨‍⚕️ Doctor Management
- 🧑‍🤝‍🧑 Patient Management
- 🏢 Department Management
- 📅 Appointment Management
- 🛡️ Insurance Management
- 🔄 CRUD Operations
- 🗂️ DTO Support
- 🛢️ Database Integration using Spring Data JPA
- ⚡ Layered Architecture (Controller → Service → Repository)

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
